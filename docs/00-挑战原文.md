# Challenge C2：AI for Math 论文

> 围绕 AI4Math 可靠性框架撰写一篇可投稿 LaTeX 学术论文——证明你能产出学术级别的成果。

难度：进阶 · 建议周期：5 天 · 单人

## 一、挑战定义

AI 做数学（AI4Math）领域，模型会给出看似正确实则错误的证明。学界用"可靠性框架"回应：搜索 + 验证、形式化证明、可复现评估。你的任务：**以 AI4Math 可靠性为主题，产出一篇结构完整、可投稿的 LaTeX 学术论文**。

重点不是数学多深，而是**学术写作与 AI 协作研究**：提出问题 → 调研文献 → 建立框架 → 论证 → 排版投稿。

## 二、学习目标

1. 完成一次"AI 辅助学术研究"闭环：选题、文献检索、框架构建、写作、LaTeX 排版；
2. 学会用 AI 做文献综述与批判性阅读（对比、找漏洞、找共识），而非搬运摘要；
3. 掌握 LaTeX 学术论文规范（结构、引用、图表、公式），产出可编译的 paper.tex；
4. 对"AI 结论可信度"形成自己的判断框架（搜索验证 / 形式化 / 可复现评估）。

## 三、交付物（required_deliverables）

| 文件 | 说明 |
|---|---|
| `paper.tex` | 论文主文件，可独立编译（pdflatex/xelatex） |
| `references.bib` | BibTeX 引用库（≥ 8 篇，含一手文献） |
| `*AI日志*` | 每日 AI 协作日志 |
| `*AAR*` | 复盘文件（七维 AAR） |

## 四、验收要点

- 论文含完整结构：摘要、引言、相关工作、方法/框架、分析、结论、参考文献；
- 框架有原创性贡献（哪怕是小贡献：一个新的分类、一个对比实验、一个可靠性清单）；
- `paper.tex` 可编译，图表公式排版规范，引用可解析；
- 文中所有"AI 生成结论"均有人工核验记录（AI 日志可追溯）。

## 五、评分标准（Rubric，100 分制）

| 维度 | 满分 | 要点 |
|---|---|---|
| researchRigor 研究严谨性 | 25 | 文献真实可查、论证有据、框架有原创贡献、结论有边界 |
| technicalExecution 技术实现 | 20 | LaTeX 可编译、结构规范、图表公式质量 |
| artifactCompleteness 产物完整性 | 15 | paper.tex + references.bib 齐全 |
| aiUsage AI 使用质量 | 20 | 文献调研/写作迭代有记录，AI 结论经人工核验 |
| reflectionQuality 复盘质量 | 20 | 七维 AAR 实质内容，含"AI 误导"案例与对策 |

**红线**：引用造假 → 研究严谨性 0 分；不可编译 → 技术实现 ≤ 5。
