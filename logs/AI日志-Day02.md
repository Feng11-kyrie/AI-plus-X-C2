## 3. 本日新发现的 AI 使用风险（写进 AAR 的素材）

**风险 1：搜索结果 ≠ 可引用文献 —— 差点踩引用造假红线**
- 现象：WebSearch 返回的 emergentmind / tomesphere 条目是**二手转述**，页面上没有作者、卷期、arXiv 编号的完整可核对信息。
- 风险：如果直接把这些页面当文献引用，就是「引用造假」——**研究严谨性直接 0 分**。
- 处置：顺着线索找到一手来源 arXiv:2511.03108，核对作者、日期、编号、摘要原文后才写入 `.bib`。
- 教训：**任何从搜索引擎摘要里拿到的文献，必须回到出版方页面核对一次再引用。**

**风险 2：AI 写综述的默认形态就是「搬运摘要」**
- 现象：AI 首版 Related Work 只有 5 行，句式全是「某某做了什么」。
- 对照：`CHALLENGE.md` 学习目标第 2 条明确要求「对比、找漏洞、找共识，**而非搬运摘要**」。
- 处置：改成统一提问框架——**「这条工作默认什么东西已经给定？」**，三条线的答案都是「形式化语句或可执行求值器」，即 Layer 2 的产物。这个统一答案本身就构成了本文对文献的判断（consensus + gap）。
- 教训：让 AI 写综述时，指令里必须给出**提问角度**，否则它只会复述。

## 5. 环境突破：本机 LaTeX 红线已拆除

- 本机原无 pdflatex / xelatex / latexmk / tectonic，且无 brew。
- 方案：从 GitHub Releases 直接拉取 **tectonic 0.17.0 aarch64-apple-darwin** 自包含二进制（无需安装器、无需 root），置于 `~/.workbuddy/binaries/tectonic/`。
- 结果：本地即可完整编译（含 bibtex），**不再依赖 Overleaf**。
- 意义：消除「不可编译 → 技术实现 ≤ 5 分」这条唯一未验证的红线。
