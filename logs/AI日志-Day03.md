**决策**：走**保守路**，但把「没跑」做成有价值的产出，而不是一句免责声明。具体三件事：

1. **示例计算**：用已发表数据（arXiv:2511.03108 的 97% / 69% / 36%）代入本文的分解恒等式，算出不可审计项约 31 个百分点。这是**在别人已发表数字上做算术**，不是我自己造数据。
2. **报告模板表**：把「该报告什么」固化成一张空表，明确禁止用 $a$ 和 $\nu$ 反推 $\alpha$。
3. **可证伪条件**：预先写清什么结果会推翻我的论点。

> 判断依据：挑战的验收要点点名接受三种原创贡献形式——「一个新的分类 / 一个对比实验 / 一个可靠性清单」。**我已经占了分类和清单两项**，实验不是必需的。而编造实验数据会直接触发红线，收益远小于风险。

## 4. 本阶段的 AI 使用风险

**风险 3：AI 倾向于把「没做实验」写成一句轻描淡写的免责声明**
- 现象：AI 初稿的 honest status 只有三行，句式是「需要超出本文范围的工程量」。
- 问题：这是**回避**，不是诚实。评审会认为你在藏拙；而挑战的 negativeSignals 明确列了「凭空断言」。
- 处置：改成**具体说明为什么做不到**（无 API 凭据、两个数据源的实际错误码都写出来），并把「没跑」转化为三项具体产出（示例计算 / 报告模板 / 可证伪条件）。
- 教训：**诚实要具体到可核查**，具体到给出失败命令的错误码，比含糊说「条件不足」有力得多。
