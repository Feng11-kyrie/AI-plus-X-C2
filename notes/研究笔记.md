# 研究笔记（零散思考与判断依据）

> 这里记的是**判断过程**，不是结论。结论在 `paper/paper.tex`，核验记录在 `docs/` 与 `logs/`。

---

## 1. 为什么是「语义规约层」而不是别的

一开始我把 AI4Math 的不可靠归结为「模型会胡说」。但读了素材之后发现这个说法太粗：

- 如果只是生成层不行，那加强验证就行 —— 但验证器根本拿不到可检查的对象。
- 如果验证层不行，那换个更强的证明器就行 —— 但 Lean 4 的内核是可靠的，形式化过的证明就是对的。

所以真正的断点是**中间那层**：自然语言不是可计算对象，而验证器只能作用于可计算对象。中间必须有个东西把前者变成后者，而所有失败都堆在这个转换里。

这个判断后来在 arXiv:2511.03108 上得到了印证：**自动形式化 97% + 定理证明 69%，组合起来只剩 36%**。两个强组件拼起来远弱于任一组件，损失只能发生在接口上。

## 2. 分解恒等式是怎么想到的

想要一个能反驳「报告准确率 = 可靠程度」的式子。核心观察：

> 一道题「答对了」和「答对这件事可以被检查」是两件不同的事。

于是按能否规约把题目分成 $V$ 和 $V^c$：

$$a = \alpha + (1-\nu)u$$

右边第二项就是**答对了但没法审计**的那部分。它的存在意味着：**一个系统可以一边提高 $a$，一边降低 $\nu$** —— 变得更会答，却更不会讲可验证的理由。而现有基准只看 $a$，所以看不出来。

这条式子我自己手推的，不是 AI 给的（AI 给的初版是错的量纲）。

## 3. 分类法为什么强调「机器可检测」

如果只是描述性地分成四类，那就是个普通的错误清单，没有贡献。所以我给每一类都配了一条**系统能自己判定**的判据：

- 歧义 → 解析重数 > 1
- 类型省略 → 精细化后仍有未消解元变量
- 指称漂移 → IR 图上存在未消解/多候选共指边
- 不可逆 → round-trip 不一致

这样分类法才是**可报告的**，而不是只有人能判断。最右边一列「验证器是否可见」全是「否」——这就是「瓶颈」的严格含义：**加强邻居补不了这一层**。

## 4. 关于「没跑实验」这件事

试过，跑不动：GitHub raw 拉 GSM8K 超时（exit 28），HuggingFace 镜像连接失败（HTTP 000），也没有模型 API 凭据。

我的处理是把它变成三项产出，而不是一句免责声明：
1. 在别人已发表数字上做示例计算（明确标注是 illustration + 独立性假设未辩护）
2. 报告模板表（并规定 $\alpha$ 必须实测，不得由 $a$、$\nu$ 反推）
3. 预先写清可证伪条件（含最强一条：若强制执行清单反而提高 $a$，则我的权衡主张被推翻）

理由：编数据是这个领域最典型的翻车方式，也是本挑战的 0 分红线。而验收要点点名接受「一个新分类 / 一个对比实验 / 一个可靠性清单」——我已经占了分类和清单两项，实验不是必需的。

## 6. 一句提醒（给未来的自己）

论文里每一个数字，都要能指到引用来源或自己的推导。写的时候觉得「这个数大概是 X」，不查就写进去，后面一定会被自己的核验表拦下来。
